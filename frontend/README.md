# The Sender Moto — Frontend (Next.js 16)

ส่วนหน้าบ้าน (Customer Booking Landing Page) และระบบจัดการหลังบ้าน (Admin Dashboard) ของ **The Sender Moto**

## คำสั่งที่ใช้บ่อย

```bash
# รันเซิร์ฟเวอร์สำหรับพัฒนา (http://localhost:3000)
npm run dev

# ตรวจสอบ ESLint
npm run lint

# ตรวจสอบ TypeScript
npx tsc --noEmit

# สร้าง Production Build
npm run build
```

ดูรายละเอียดการตั้งค่าฐานข้อมูลและระบบทั้งหมดได้ที่ไฟล์ [../README.md](../README.md) ที่โฟลเดอร์หลักของโปรเจกต์
